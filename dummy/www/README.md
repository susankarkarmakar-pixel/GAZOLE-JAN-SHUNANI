# 🏛️ GAZOLE JAN SHUNANI

**গাজোল জনশুনানি** - Public Grievance Hearing & Redressal System

## 📋 Overview

A comprehensive digital grievance management system for the Gazole Block Development Office, West Bengal. This system enables citizens to submit complaints, track their status, and allows government staff to manage and resolve grievances efficiently.

## ✨ Features

###  Public Features
- **Submit Complaint** - Multi-step form with file upload
- **Track Status** - Real-time complaint tracking with timeline
- **View Grievances** - Searchable and filterable list
- **Bilingual Support** - English + Bengali throughout
- **Mobile Responsive** - Works on all devices

### 👨‍💼 Staff Features
- **Officer Login** - Secure authentication
- **Dashboard** - Analytics and statistics
- **User Management** - Create and manage system users
- **Status Updates** - Update complaint status with actions
- **Category Management** - Add new complaint categories

## 🎨 Design System

- **Primary Color**: Deep Blue (#003b5a)
- **Accent Color**: Orange (#e67e22)
- **Typography**: Inter + Noto Sans Bengali
- **Layout**: Card-based, mobile-first
- **Navigation**: Bottom navigation bar

## 🚀 Deployment

### GitHub Pages

1. Upload all files to a GitHub repository
2. Go to **Settings** → **Pages**
3. Select **main** branch and **/ (root)** folder
4. Click **Save**
5. Your site will be live at: `https://yourusername.github.io/gazole-jan-shunani/`
